# 스프라이트 넣는 곳

이 폴더에 `<디지몬 이름>.png` 파일을 넣으면 임시 도형 대신 그 그림이 표시됩니다 (gif, webp도 가능).

- 파일 이름은 게임 안의 이름과 똑같이: `아구몬.png`, `메탈그레이몬(청).png`, `가루몬(흑).png`
- 알은 `디지에그.png`
- 크기는 자동으로 맞춰집니다. 배경이 투명한 PNG를 권장합니다.
- 16×16, 32×32 같은 작은 도트(64px 이하)는 정수 배율로 확대되고, 흐려지지 않게 최근접 필터로 그려집니다.
- 이름 목록은 `src/data/evolutions.txt`에 있습니다.
- 넣은 뒤 `npm run dev`를 다시 실행하면 반영됩니다.
