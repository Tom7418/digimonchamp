# 디지몬 챔피언십 · 테이머 가든

**플레이:** https://tom7418.github.io/digimonchamp/

현재 홈페이지는 NDS 디지몬 챔피언십의 시스템을 옮긴 브라우저 팬게임입니다. 화면(`web/`)은 원본에서 변환한 스프라이트와 육각 케이지 사육장을 쓰고, 규칙은 `src/core`의 엔진을 `web/core.js`로 빌드해 그대로 사용합니다.

## 현재 홈페이지

- 디지에그에서 시작 (30분 뒤 깜몬 부화), 현실10초마다 게임10분 갱신, 꺼 둔 시간도 최대 게임 12시간 반영하되 23:59 달력에서 멈춤. 다음 날 버튼으로 아침 7시에 시작
- 여러 마리 사육: 원본 도트의 고기 선택 → 바닥 터치로 배치 → 배고픈 디지몬이 걸어와 한 입씩 먹기(남은 고기 저장·4단계 도트). 약은 병 치료, 상처약은 부상 치료, 알약(프로틴)은 바닥에 놓아 먹이면 다음 배틀 공격 강화. 선택 / 이동 버튼 또는 Esc로 도구 해제
- 청소: 빗자루 클릭·드래그로 똥과 남은 고기·상한 고기·프로틴을 함께 치우기. 먹이는 회수하지 않고 폐기
- 화면 조작: 휠 확대·축소(0.5~2.5배), 선택 / 이동 상태에서 빈 바닥 드래그로 카메라 이동. 디지몬은 현재 도트의 몸 부분을 눌러 선택·끌기·쓰다듬기
- 케이지 편집: 상점에서 산 케이지를 설치하고 디지몬을 끌어 넣으면 게임15분 뒤 원본 시설 결과표에 따라 능력치·종족·속성·내성이 오르거나 내려감. 훈련은 배치당 한 번. 파트너 패널의 ‘케이지 훈련 효과’에서 설치 시설별 현재 계절 결과와 발생 비율·증감 범위 확인
- 진화 220여 종: 속성 수치 / 배틀 횟수 / 페널티 / 디지에그화 / 시간 경과, 진화 조건표 표시. 원본 진화 이펙트·실루엣으로 진화 전후 모습을 재생하며 동시 진화는 순서대로 표시
- 능력치: 원본 곡선에서 종별 초기값 생성, 진화 때 이전 훈련 성과 일부 이월. 이전 저장은 원래 수치를 보관하고 한 번 변환
- 배틀: 같은 HP·TP 단위로 필드 자동 전투, 출전 전 공격 방식(일반·지원·특수), 프리 배틀 ★1~3 (1:1, 3:3)
- 타이틀 매치(첫 타이틀 봄 3일 ‘에이스 오브 링’) → 테이머 랭크 업 → 사육 용량·케이지 공간·진화 가능 세대 증가 (레드 테이머: 96G, 16칸, 성숙기)
- 챔피언십: 가을 1~5일 예선(3승 통과) → 다음 해 가을 5일 본선 8강·4강·결승 → 우승 시 챔피언(랭크 9)
- 상점: 고기, 알약, 케이지, 로프, 메모리카드, 와이어
- 그림: 진화표 216종 전부와 디지에그를 원본에서 변환한 스프라이트로 표시 (파일명 ↔ 한글 이름: `tools/sprite_names.json`)
- 사냥: 원작 사냥터 16곳(랭크·계절·밤낮별 출현), 로프 12종·내구력과 메모리카드 용량, 원본 낮·밤 지도와 ATR 차단 지형 적용(안전한 바닥에 출현, 이동·도주·설치 시 벽 판정). 로프로 둘러싸 당겨 포획, 와이어로 길 막기, 08~22시
- 배틀 장소: 원본 배경11종. 일반 배틀은7종 무작위, 타이틀은 원본 장소 지정/미지정 규칙, 챔피언십은 돔 스타디움
- 아직 웹판에 없는 것: 필살기 연출, 사운드

규칙 수치 중 원작에서 확인한 것과 임시 값은 `docs/design.md`와 `src/core/titles.ts` 주석에 구분해 두었습니다.

### 수정과 배포

`web/`이 실제 홈페이지입니다. `main`에 변경을 올리면 GitHub Actions가 파일을 검사하고 GitHub Pages로 배포합니다. 접속자는 로컬 서버나 Node 설치가 필요 없습니다.

```text
web/index.html          화면 구조
web/style.css           반응형 스타일 (championship.css: 추가 스타일)
web/game.js             화면 그리기·입력·저장 (규칙은 core.js 호출)
web/core.js             src/core 규칙 엔진 빌드 결과 (npm run build:core, 직접 수정 금지)
web/cage-layout.js      육각 케이지 배치·회전·정원·케이지 공간
web/cage-editor.js      케이지 편집 입력과 그리기
web/animation.js        상태별 원본 프레임 재생기
web/assets/             PNG 스프라이트 시트와 메타데이터
tools/extract_sprites.py 원본 Nitro 리소스 변환
tools/check_web.py       배포 경로·이미지 검사
```

저장소 **Settings → Pages → Source**는 **GitHub Actions**로 설정합니다. 배포 진행은 **Actions → Deploy to GitHub Pages**에서 확인합니다.

로컬 개발 시에는 `web/index.html`을 직접 열거나 `python -m http.server 8080 --directory web`으로 미리 봅니다. 직접 파일을 열 때의 저장 공간은 홈페이지 저장 공간과 별개입니다.

### 리소스와 검증

현재 게임에 쓰이는 변환 PNG와 변환 도구만 포함합니다. ROM, 원본 DS 바이너리, 대용량 사운드 아카이브, 로컬 저장 데이터와 배포 인증 정보는 업로드하지 않습니다. 그림은 NCER 셀/OAM과 프레임별 VRAM 전송 위치, NCBR 그래픽, NCLR 팔레트를 조합해 생성했습니다. NANR에서 추출한 프레임 순서·유지 시간을 사육장 대기·걷기·먹기와 초상화에 적용했습니다. 동작 번호 대응과 60Hz 재생은 임시 해석이며, 사냥에도 실제 이동에 맞춘 대기·걷기를 적용했습니다. 전용 도주·훈련·수면·전투 동작은 후속 작업입니다.

원본 `digimon/` 폴더가 들어 있는 디렉터리를 지정해 다시 변환합니다. Python 표준 라이브러리만 사용합니다.

```powershell
python tools/extract_sprites.py --source-root "원본 자료가 있는 폴더"
python tools/extract_animations.py --source-root "원본 자료가 있는 폴더"
npm run build:core   # src/core를 바꿨다면 web/core.js 다시 만들기
npm test             # 규칙 엔진(vitest) + 케이지 배치(node:test)
python tools/check_web.py
```

디지몬 및 원본 그래픽의 권리는 각 권리자에게 있습니다. 비공식 비영리 팬게임이며 공식 게임과 관계가 없습니다. MIT 라이선스는 자체 작성 코드에 적용되며 원본 디지몬 리소스의 권리를 부여하지 않습니다.

## 기존 챔피언십 구현 (참고용으로 보존)

기존 Phaser/TypeScript 소스(`src/`), 테스트(`tests/`), 진화 데이터와 설계 문서는 보존했습니다. 현재 Pages 배포에는 포함하지 않습니다. 다음 내용은 기존 프로젝트의 개발 방법과 구현 내역입니다. 별도 문서는 [기존 프로젝트 문서](docs/champion-tamer.md)에 있습니다.

## 실행
```
npm install
npm run dev      # 개발 서버
npm test         # 핵심 로직 테스트
npm run build    # dist/ 생성
```

## 구현된 것
- 사육: 여러 마리 동시 사육(용량 200G), 먹이·청소·치료, 병·부상, 수명, 성격 8종
- 케이지: 훈련 케이지에 넣어 두면 능력치와 종족·속성 수치가 오른다
- 진화: 유년기I~궁극체 220여 종. 속성 수치 / 배틀 횟수·승률 / 페널티(발병) / 디지에그화 횟수 / 시간 경과
- 테이머 랭크: 타이틀을 따야 다음 세대로 진화할 수 있다
- 디지에그화와 로스트, 썩은 고기로 페널티 쌓기
- 배틀: 필드 위 자동 전투, 출전 전에 일반·특수·지원 공격 선택, 1:1과 3:3, 제한 시간
- 프리 배틀, 타이틀 매치(날짜 지정), 챔피언십 예선·본선
- 사냥: 로프로 원을 그려 포획 (유년기 서식지와 계절 반영)
- 상점, 달력(계절 10일 × 4), 자동 저장

## 원작과 다른 점 / 아직 없는 것
- 그림과 소리는 임시(색 원 + 이름표, 무음). `src/assets/sprites`, `src/assets/sounds`에 파일을 넣으면 바뀐다
- 종족·속성은 원본 실행 코드의 디지몬 표 값이다(src/data/species.txt). 능력치 수치는 원작 값을 확인하지 못해 추정했다
- 타이틀 매치의 이름·일정·상금, 케이지 일부(수영장·새장·묘지·연구실), 수명 길이, 달력 길이는 임시로 정한 값이다
- 필살기 이름과 개별 연출, 내성(더위·추위 등), 케이지 랭크 업, 사냥 도구(탄환·트랩·와이어), 성장기 이상 야생 디지몬, 기억 진화, 통신 대전은 아직 없다

## 구조
- `src/data/evolutions.txt` 진화 표 (한 줄에 한 종)
- `src/core/` 화면과 무관한 게임 규칙: data, care, evolution, battle, titles, save
- `src/scenes/` Phaser 화면: Boot, Farm(사육장), Battle, Hunt
- `src/ui/art.ts` 스프라이트·소리 끼우는 자리
