# 케이지 편집과 디지몬 입장

1. 사육장 아래 **케이지 편집**을 누릅니다. 편집 중 육성 시간은 멈춥니다.
2. 케이지 종류를 선택합니다. 사육장 위의 초록색 미리보기는 배치 가능, 빨간색은 겹침 또는 경계 이탈입니다.
3. **회전**으로 방향을 정하고 빈 칸을 눌러 설치합니다.
4. 종류 버튼을 다시 누르면 설치 도구가 해제됩니다. 설치된 케이지를 끌어 이동하거나 선택 후 회전·철거할 수 있습니다.
5. **편집 완료** 후 디지몬을 케이지 안으로 끌어 넣습니다. 파트너 선택 후 케이지를 누르는 방식도 지원합니다.
6. 빈 칸으로 끌어내면 자유 활동으로 돌아갑니다. 케이지 철거 시에도 입장한 디지몬은 자유 활동으로 돌아갑니다.

기본 케이지 1칸/1마리, 일자 체육관 3칸/2마리, 삼각 운동장 3칸/2마리, 양호실 1칸/3마리입니다. **점유 칸 수와 디지몬 정원은 별개입니다.** 설치 위치·회전·디지몬의 시설 배정은 기존 저장과 함께 현재 브라우저에 저장됩니다.

시설 배경은 원본 `training/field_cm01_01`, `field_cm02_01`, `field_cm04_01`, `field_cm16_01`의 NBSR 지도·NCGR 타일·NCLR 팔레트를 해독해 복원했습니다. 미리보기와 설치 영역은 같은 점유 좌표를 사용하며, 배경은 시설 전체에 한 번만 그립니다. 별도의 움직이는 오브젝트·효과는 아직 합성하지 않습니다. 정원과 훈련 수치는 웹 프로토타입 규칙입니다.

구버전 배치는 `layoutBackup`에 남긴 뒤 새 모양으로 변환합니다. 충돌 시설은 빈자리로 이동하고 공간이 없으면 `storedCages`에 보관합니다. 보관된 시설은 같은 종류를 선택하여 재설치할 수 있습니다.

## 코드 위치

- `web/cage-layout.js`: 육각 축 좌표, 회전, 경계·겹침 검사, 정원, 저장 복원
- `web/cage-editor.js`: 마우스/터치 입력, 설치·이동·철거, 원본 아이콘 그리기
- `web/cages.js`: 배정된 시설의 시간 경과 훈련·회복
- `web/game.js`: 저장, 게임 시간, 전투와 편집의 상호 배제
- `tools/extract_cage_icons.py`: 원본 아이콘 재변환 진입점
