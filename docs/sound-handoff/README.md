# 디지몬 챔피언십 원작 사운드 인수인계

원작 사운드의 **목록과 재생 조건을 확인하는 자료**다. 공개 웹판은 현재 행동 효과음 18종과 사냥터별 합성 환경음을 재생한다. 아래 원작 대응은 아직 웹판에 연결하지 않았다.

CSV는 한글을 포함한 UTF-8 BOM 형식이다. 전체 목록의 `FAT 파일 ID`는 재생 인자와 별개다. 같은 SSAR에 속한 효과음은 FAT 파일 하나를 공유하므로, 파일 ID만으로 개별 효과음을 식별할 수 없다.

## 확인 수준

- **동작 확인**은 이름과 실제 동작 사이의 코드 경로를 확인한 항목이다. 현재 전체 목록에서 21개다.
- **정적 상수 후보**는 호출 직전의 레지스터 상수와 SDAT 심볼을 맞춘 항목이다. 화면 진입이나 승패 같은 상세 조건은 추가로 확인해야 한다.
- **호출만 확인**은 재생 함수 호출은 찾았으나 인자가 테이블·레지스터·스크립트 등에서 들어오는 경우다. 인자를 비워 두었다. **목록 확인**은 SDAT에 있는 이름과 번호를 확인한 항목이다.
- 호출 집계는 ARM 코드에서 직접 분기하는 다섯 함수만 대상으로 했다. 간접 호출, Thumb 코드, VM 내부 호출, 재생 함수의 다른 진입점은 집계 범위 밖이다. 집계가 0이어도 미사용이라고 단정할 수 없다.

## 장면별로 확인한 내용

### 사냥

사냥 시작 시 `overlay9_0:0x0211A170`에서 배경곡을 선택한다. 사냥터 16곳이 8개 곡을 공유하며, 각각의 낮·밤 지도는 같은 곡이다. 일반·연사 샷은 `0x0408`, 산탄은 `0x040A`, 선을 그리는 동안의 루프는 `0x0800`이다. 전체 대응은 사냥터 표에 있다.

### 배틀

배틀 오버레이 `overlay9_19:0x0210F4C0`은 게임 상태의 맵 번호(`+0xC9C`)를 배틀 객체에 저장한다. `0x021134B8–0x0211359C`가 이 번호를 읽어 음악을 고른다. 예를 들어 초원·섬은 `SEQ_U_15`, 화산·사막은 `SEQ_N_11`, 돔 스타디움은 `SEQ_N_12`다.

배틀용으로 이름이 지정된 리소스는 `SEQARC_SE_BATTLE` 27개, `SEQARC_SE_BATTLE_LOOP` 2개, `STRM_BATTLE_*` 27개다. 각 기술·피격에 어떤 리소스를 쓰는지는 개별 호출이나 기술 스크립트를 따라 확인한다. 파일명의 숫자를 기술 레코드 번호와 동일하게 취급하지 않는다.

## Claude가 이어갈 때

1. **확인된 배경곡 매핑부터 연결.** 사냥은 사냥터 ID, 배틀은 맵 ID를 키로 사용한다. 사냥에서 낮·밤만 바뀌면 같은 배경곡을 이어서 재생한다.
2. **효과음의 시점을 사건에 맞춘다.** 먹이는 한 입을 실제로 소비하는 경로, 배틀 피격은 시각적 명중 처리, 사냥 선 그리기는 시작과 종료가 있는 루프다. 메뉴 이동이나 버튼 클릭으로 뭉뚱그리지 않는다.
3. **다음 검증 순서.** 첫 우승 메달과 일반 승패의 징글 구분 → 육성 배경곡·부화·진화 → 배틀 기술별 재생 인자 → 샷 이외 사냥 장비와 UI·훈련 효과음. 미확인 항목은 각 호출의 직전 조건이나 간접 테이블을 추적한다.
4. **웹 연결 위치.** `web/game-audio.js`는 음량·음소거·브라우저 오디오 활성화와 이벤트 효과음을 관리한다. `web/hunt-audio.js`는 현재 사냥 합성 환경음 전용이다. `web/game.js`의 사냥 루프·`battleHitVisual`·`finishBattle`·먹이 처리에서 재생 사건을 전달한다. 기존 게임 저장과 소리 설정 키 `champion-sound-v1`을 이어받는다.
5. **검증 기준.** 사냥은 같은 곡을 공유하는 곳과 다른 곡을 쓰는 곳을 각각 비교한다. 배틀은 같은 맵의 다른 대회, 첫 우승과 재우승, 방어와 명중을 확인한다. 소리 끄기·탭 숨김·사냥 퇴장·재입장 후 중복 재생도 확인한다.

인수인계 묶음은 이름·번호·주소·판정 메모만 포함한다. 공개 배포를 위한 음원은 별도로 준비한다.

## 로컬 원본 대조 방법

- `root/sound_data.sdat`의 `SYMB`에서 이름, `INFO`에서 파일 ID, `FAT`에서 컨테이너 시그니처와 크기를 확인한다. 소스 위치는 `root/ftc/arm9.bin` 및 `overlay9_*`다. ARM9 기준 주소는 `0x02000000`, 오버레이 기준 주소는 `y9.bin`에서 읽는다.
- `0x0203E044`는 시퀀스 시작, `0x0203E0E4`는 시퀀스 정지, `0x0203E138`과 `0x0203E218`은 스트림 시작·정지다. `0x0203DEC4`에서 일반 효과음은 상위 바이트가 시퀀스 아카이브 번호, 하위 바이트가 항목 번호다. 상위 바이트가 `FF`이면 하위 바이트를 스트림 번호로 사용한다.
- 정적 후보는 위 다섯 함수로 직접 분기하는 위치를 찾아, 직전 최대 12개 ARM 명령 안에서 `r0`의 즉시값 또는 PC 상대 상수를 찾는 방식으로 수집했다. 분기·함수 호출이나 해석되지 않은 `r0` 대입을 만나면 추적을 중단했다.
- 원본 SDAT SHA-256은 `2aa95452bd2a917a19fcf5fbf673e942eda59d5dcef162b82a53e46ed0670ddd`다.
