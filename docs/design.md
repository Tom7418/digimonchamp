# 디지몬 챔피언쉽 팬게임 — 기획 (3판, 2026-11-12)

디지몬 챔피언쉽(NDS, 2008)의 시스템을 웹으로 다시 구현하는 비영리 팬게임.
디지몬 이름·진화 루트·진화 조건은 공개 공략 위키(나무위키 진화 목록)의 내용을 게임 데이터(`src/data/evolutions.txt`)로 옮겼다.
규칙 엔진은 `src/core`, 화면은 `web/`. 엔진은 `npm run build:core`로 `web/core.js`가 된다.
그림: `web/assets`에 원본 Nitro 리소스에서 변환한 PNG 217장(디지에그 + 진화표 216종 전부). 원본 파일명과 한글 이름 대응은 `tools/sprite_names.json`.

## 원작에서 가져온 규칙
- 세대: 유년기I → 유년기II → 성장기 → 성숙기 → 완전체 → 궁극체 (220여 종)
- 진화 조건: 속성 수치 / 배틀 횟수(승률) / 디지에그화 횟수 / 발병 횟수(페널티). 아무것도 못 채우면 수명이 다할 때 시간 경과 진화
- 표의 위에서부터 검사해 처음 충족하는 쪽으로 진화
- 디지에그화: 완전체 이상이거나 배틀 10회 이상이면 수명이 다할 때 알로 돌아감. 그렇지 않으면 로스트
- 디지에그화를 거칠수록 요구 수치가 조금 줄어듦
- 썩은 고기 두 개를 먹으면 병 (페널티)
- 케이지에 넣어 두면 정해진 능력치·속성이 오르고 반대쪽은 내려감
- 성격 8종, 능력치 HP·TP·공격·방어·지능·민첩
- 배틀은 자동, 출전 전 일반·지원·특수 선택. 프리 배틀, 타이틀 매치, 챔피언십(가을 예선 → 다음 해 본선)
- 사냥: 로프로 둘러 포획, 서식지와 계절
- 시작: 디지에그 → 깜몬

## 플레이 영상으로 확인한 것 (YouTube RmZxzNaH-rs, 한국어판 실기 26분)
화면
- 두 화면 나란히: 왼쪽 아이소메트릭 육각 사육장(운동장 트랙, 보건실, 바닥의 똥), 오른쪽 정보창
- 정보창 상단 띠: 계절 · N일 · 모드(육성/사냥/배틀/상점) · 시각 · 비트. 본문 HP/TP/FP/용량, 보유 디지몬 아이콘 줄
- 배틀: 필드 자동 전투(Auto), 매치 이름·팀 이름·제한 시간 120·HP 막대, 승리 시 WIN과 랭크 업 메시지

진행
- 이름 등록 → 디지에그 이름 → 튜토리얼(부화, 운동장에서 HP 상승, 배고프거나 HP가 줄면 보건실, 자는 동안 사냥)
- 하루는 밤 9시쯤 끝남. 일정표 체크 표시 날이 타이틀 매치
- 첫 타이틀: 봄 3일 '에이스 오브 링', 팀 에이스 1:1
- 타이틀을 딸 때마다 랭크 업. 세 번째 타이틀에서 '레드 테이머': 최대 용량 96G, 케이지 공간 16, 성숙기 진화 허용
- 랭크 업 시 상점 품목 추가 (사냥 도구 등)
- 프리 배틀은 매일 가능, 지면 부상. NPC가 디지몬을 비트로 사겠다는 이벤트
- 사냥: 여러 사냥터, 도망가는 디지몬을 와이어로 막음, 로프로 둘러 당기면 HP가 깎이고 다 깎아야 포획, 성장기는 성장기용 로프 필요, 용량이 차면 놓아줄 디지몬 선택

진화 예 (게임 내 진화표, evolutions.txt와 일치)
- 뿔몬: 가오몬(배틀 3) / 파피몬(짐승 20) / 사이케몬(데이터 10 + 페널티 3) / 에렉몬(시간)
- 아구몬: 그레이몬(배틀 6) / 스카몬(페널티 4) / 티라노몬(시간)
- 레나몬: 구미호몬(짐승 20) / 스카몬(시간), 구미호몬 → 가루다몬(새 40 + 배틀 8)
