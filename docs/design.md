# Champion Tamer (가제) — 0단계 기획

디지몬 챔피언쉽(NDS, 2008)의 육성·자동배틀 구조를 모티브로 한 비영리 팬게임.
원작 ROM, 그림, 음원, 몬스터 데이터는 사용하지 않는다. 몬스터는 모두 오리지널이며,
데이터(JSON)와 그림(절차적 생성 → 추후 스프라이트 교체)이 코드와 분리되어 있다.

## 화면 구성
- DS처럼 위·아래 두 화면 (각 512×384, 전체 512×768)
- 위: 사육장 (몬스터, 똥, 시간, 상태 아이콘)
- 아래: 상태 패널 + 행동 메뉴

## 시간
- 현실 1초 = 게임 1분, 게임 하루 = 현실 24분
- 꺼져 있던 시간도 흐르되 최대 게임 12시간까지만 반영 (방치 사망 방지)
- 개발용 배속 버튼 (×1 / ×10 / ×60)

## 진화 단계 (6단계, MVP는 완전체까지)
| 단계 | 기본 체류 시간(게임) |
|---|---|
| 알 | 30분 |
| 유년기1 | 2시간 |
| 유년기2 | 6시간 |
| 성장기 | 24시간 |
| 성숙기 | 48시간 |
| 완전체 | (MVP 최종) |

## 초기 몬스터 (오리지널, 13종)
- 알 → 포코(유년기1) → 포코롱(유년기2)
- 성장기: 이그니(힘), 루미(지능), 그루(방어)
- 성숙기: 이그니스, 볼카노, 루미엘, 스톤가드, 머드버그(돌봄 실수 많음)
- 완전체: 플레어드레이크, 셀레스티아, 타이탄록

## 육성 수치
- 능력치: HP, 공격(ATK), 방어(DEF), 속도(SPD), 지능(INT)
- 상태: 배부름 0~100, 기력 0~100, 체중, 똥 개수, 아픔 여부
- 기록: 돌봄 실수, 훈련 횟수, 배틀 수, 승리 수
- 돌봄 실수: 배부름 0이 1시간 지속, 똥 3개 이상 방치, 아픔 방치

## 행동
- 먹이: 배부름 +30, 체중 +1
- 영양제: 배부름 +10, 체중 +2, HP +5
- 훈련(힘·방어·속도·지능): 해당 능력치 상승, 기력 −15, 배부름 −5, 체중 −1
- 청소: 똥 제거 / 치료: 아픔 해제 / 휴식: 기력 회복

## 진화 규칙
- 체류 시간이 다 차면 후보를 우선순위대로 검사, 조건을 처음 만족하는 쪽으로 진화
- 조건 항목: 능력치 최소값, 돌봄 실수 최대값, 훈련 수, 배틀 수, 승리 수
- 어느 조건도 못 맞추면 기본(마지막) 후보로 진화
- 진화 힌트 UI: 후보는 "???"로 표시하고 조건 충족 여부만 보여 준다 (원작의 불친절함 보완)

## 자동 배틀
- 1:1, 틱 기반 시뮬레이션. 속도만큼 행동 게이지가 차고 100이 되면 행동
- 출전 전 AI 성향 선택: 공격형 / 균형형 / 신중형
- 기술은 종족별 2~3개, 물리(ATK) / 특수(INT) 구분
- 결과는 순수 함수로 계산해 로그를 만들고, 화면은 로그를 재생한다
- 배틀 후 기력·배부름 감소, 승리 수 기록

## 이후 단계에서 다룰 것
- 토너먼트 일정과 랭크, 포획 미니게임, 스프라이트·사운드, 런처 패키징
