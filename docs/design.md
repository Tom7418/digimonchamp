# 디지몬 챔피언쉽 팬게임 — 기획 (3판, 2026-11-12)

디지몬 챔피언쉽(NDS, 2008)의 시스템을 웹으로 다시 구현하는 비영리 팬게임.
디지몬 이름·진화 루트·진화 조건은 공개 공략 위키(나무위키 진화 목록)의 내용을 게임 데이터(`src/data/evolutions.txt`)로 옮겼다.
규칙 엔진은 `src/core`, 화면은 `web/`. 엔진은 `npm run build:core`로 `web/core.js`가 된다.
그림: `web/assets`에 원본 Nitro 리소스에서 변환한 PNG 217장(디지에그 + 진화표 216종 전부). 원본 파일명과 한글 이름 대응은 `tools/sprite_names.json`.

## 원작에서 가져온 규칙
- 세대: 유년기I → 유년기II → 성장기 → 성숙기 → 완전체 → 궁극체 (220여 종)
- 진화 조건: 속성 수치 / 배틀 횟수(승률) / 디지에그화 횟수 / 발병 횟수(페널티). 아무것도 못 채우면 수명이 다할 때 시간 경과 진화
- 표의 위에서부터 검사해 처음 충족하는 쪽으로 진화
- 디지에그화: 완전체 이상이거나 배틀 10회 이상이면 수명이 다할 때 알로 돌아감. 그렇지 않으면 로스트
- 디지에그화를 거칠수록 요구 수치가 조금 줄어듦
- 썩은 고기 두 개를 먹으면 병 (페널티)
- 케이지에 넣어 두면 정해진 능력치·속성이 오르고 반대쪽은 내려감
- 성격 8종, 능력치 HP·TP·공격·방어·지능·민첩
- 배틀은 자동, 출전 전 일반·지원·특수 선택. 프리 배틀, 타이틀 매치, 챔피언십(가을 예선 → 다음 해 본선)
- 사냥: 로프로 둘러 포획, 서식지와 계절
- 시작: 디지에그 → 깜몬

## 플레이 영상으로 확인한 것 (YouTube RmZxzNaH-rs, 한국어판 실기 26분)
화면
- 두 화면 나란히: 왼쪽 아이소메트릭 육각 사육장(운동장 트랙, 보건실, 바닥의 똥), 오른쪽 정보창
- 정보창 상단 띠: 계절 · N일 · 모드(육성/사냥/배틀/상점) · 시각 · 비트. 본문 HP/TP/FP/용량, 보유 디지몬 아이콘 줄
- 배틀: 필드 자동 전투(Auto), 매치 이름·팀 이름·제한 시간 120·HP 막대, 승리 시 WIN과 랭크 업 메시지

진행
- 이름 등록 → 디지에그 이름 → 튜토리얼(부화, 운동장에서 HP 상승, 배고프거나 HP가 줄면 보건실, 자는 동안 사냥)
- 하루는 밤 9시쯤 끝남. 일정표 체크 표시 날이 타이틀 매치
- 첫 타이틀: 봄 3일 '에이스 오브 링', 팀 에이스 1:1
- 타이틀을 딸 때마다 랭크 업. 세 번째 타이틀에서 '레드 테이머': 최대 용량 96G, 케이지 공간 16, 성숙기 진화 허용
- 랭크 업 시 상점 품목 추가 (사냥 도구 등)
- 프리 배틀은 매일 가능, 지면 부상. NPC가 디지몬을 비트로 사겠다는 이벤트
- 사냥: 여러 사냥터, 도망가는 디지몬을 와이어로 막음, 로프로 둘러 당기면 HP가 깎이고 다 깎아야 포획, 성장기는 성장기용 로프 필요, 용량이 차면 놓아줄 디지몬 선택

진화 예 (게임 내 진화표, evolutions.txt와 일치)
- 뿔몬: 가오몬(배틀 3) / 파피몬(짐승 20) / 사이케몬(데이터 10 + 페널티 3) / 에렉몬(시간)
- 아구몬: 그레이몬(배틀 6) / 스카몬(페널티 4) / 티라노몬(시간)
- 레나몬: 구미호몬(짐승 20) / 스카몬(시간), 구미호몬 → 가루다몬(새 40 + 배틀 8)

## 육각 전용 시설 그림 개편
- 양호실과 운동장은 built-in image_gen으로 원본 시설을 참조해 내부 배치를 재구성한 팬게임용 이미지. 원본 PNG는 보존하고 clinic-hex.png(104×120), field-hex.png(208×210)를 사용한다.
- 양호실: 꼭짓점이 위/아래인 한 칸 육각형 안에 침대·커튼·약장을 재배치. 운동장: 위 두 칸/아래 한 칸 합집합 안에 트랙을 작게 넣고 아래는 운동 공간으로 구성. 원작 그대로의 복원 그림이 아님.
- 두 전용 그림은 점유 경계 상자에 정렬하고, 모든 시설은 회전된 점유 칸 합집합으로 최종 클리핑해 바깥 침범을 방지. 예전의 전체 그림 무클리핑 방식은 폐기.
- 생성 프롬프트: 양호실은 원본 베이지 바닥·푸른 커튼·침대·약장과 DS 도트 느낌을 보존해 정확한 정육각형으로 재구성, 외부 투명/인물·문자 없음. 운동장은 3칸 합집합 꼭짓점 (25,0),(50,14.286),(75,0),(100,14.286),(100,42.857),(75,57.143),(75,85.714),(50,100),(25,85.714),(25,57.143),(0,42.857),(0,14.286)에 맞춰 흙 트랙과 청색 울타리를 내부로 재구성, 외부 투명. 도트 해상도 정규화: tools/resize_facility.ps1.

- 양호실 테두리 편집 프롬프트(built-in image_gen): 기존 양호실 내부의 약장·시계·벤치·침대·푸른 커튼·베이지 바닥 배치를 보존하고, 외곽선만 운동장 참조와 같은 청록/파랑 분절 난간 및 정사각 기둥으로 교체. 한 칸 정육각형과 104:120 비율 유지, 모든 기둥은 경계 안쪽, 외부 투명·문자/인물 없음. 최종 파일 clinic-hex.png(104×120).

- 2026-11-13 전체 시설로 확대: 나머지 시설도 같은 모양새(점유 칸을 빈틈없이 채우고 청록 난간·기둥 테두리)로 `<이름>-hex.png`를 만들었다. image_gen이 아니라 tools/make_hex_facilities.py가 원본 cmNN.png를 정육각 격자에 맞추고 테두리를 그린다. 2~3칸 미니 시설은 큰 시설 그림에서 칸을 잘라 쓰거나(미니 화산·해변·고산·숲·공장) 한 칸 그림을 칸마다 깐다(공터·미니 화원·미니 체육관). clinic-hex·field-hex는 Codex 그림 그대로.

- 기본 바닥 편집 프롬프트(built-in image_gen): 기존 따뜻한 갈색 흙·작은 풀·돌 질감을 유지하고 모든 청록 울타리/외곽선/투명 외부를 제거, 직사각형 전체를 흙으로 채움. 울타리는 게임이 별도로 그림.

## 종별 각성·수면 주기 (후속 코드 조사)
- 원본 표 +36/+38은 각성 범위, +40/+42는 수면 범위다. overlay18 수면 진입 0x0211b888에서 동작13을 지정하고 뒤 범위를 선택, 종료 0x0211b8fc에서 앞 범위를 다음 각성 목표로 선택한다. 배설 주기로 보았던 가능성은 폐기한다.
- 객체+0x118은 추출기 레코드의 +4를 가리킨다. 원작 번호 앞에는 디지에그8개가 있으므로 표 기준점/오프셋을 섞으면 안 된다. tools/audit_life_cycle.py가 명령14개와216종 추출 값을 검증하며 docs/life-cycle-audit.json에 해시와 근거를 남긴다.
- 예: 깜몬 각성360~420/수면30~60, 아구몬 각성960~1020/수면60~120. 최대값 미포함 범위에서 한 번 뽑아 저장하고 매 틱 다시 뽑지 않는다.
- 웹판 정책: 단위는 게임 분으로 해석(원작 타이머 호출 주기 자체는 미확정). 낮잠 동안 이동·급여·훈련·허기/배설 진행 정지, 피로0.3/분 회복은 기존 야간 처리 재사용. 병·수명 진행 유지. 훈련 도중 잠들면 진행 분을 보존하고 깬 뒤 이어간다.
- 기존21시 마감→다음7시 방식 유지. 밤에 낮잠 주기를 비우고 다음 아침 새 각성 주기를 시작한다. 하루 활동14시간보다 각성이 긴 종은 통상 낮잠을 자지 않는다. 원작 주야 흐름 완전 재현과 별개다.
- 저장: optional restCycle에 종·남은 각성/수면 분을 저장. 옛 저장은 첫 틱 초기화, 종이 바뀌면 새 범위를 사용, 알로 돌아가면 제거. 먹다가 잠들어도 바닥 먹이/재고는 보존한다.
- 시설 동작은 trainDone 뒤에는 대기로 돌아가며, 잠든 동안에는 수면13이 우선한다. 14개 훈련 적성 후보는 아직 미적용: 역할/순서/계산식을 확인하지 못했다.
