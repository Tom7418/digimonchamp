# 로드맵과 현재 상태

마지막 갱신: 2026-11-13 (원본 NANR 기반 사육장 애니메이션 1차). 작업을 마치면 이 파일의 상태 표와 다음 할 일을 함께 고친다.

## 방향
- NDS 「디지몬 챔피언십」(2008)의 시스템을 브라우저로 옮기는 비공식 비영리 팬게임
- 목표는 원작과 같은 플레이 감각. 디지몬 이름·진화 루트·진화 조건은 공개 공략 위키, 화면과 진행은 플레이 영상(YouTube RmZxzNaH-rs) 기준
- HTML 웹게임으로 완성한 뒤 Tauri/Electron으로 런처화
- 배포: GitHub Pages https://tom7418.github.io/digimonchamp/ (main에 푸시하면 자동)

### 7단계 진행 상황
- 완료: 217종 NANR에서 대기·걷기·먹기 프레임과 유지 시간 추출. 사육장 상태별 재생과 초상화 대기 적용, 인위적인 상하 흔들림 제거. 먹는 동안 먹이를 예약하고 동작 완료 후 소비하며, 일시정지·편지·편집 중에는 동작도 정지. 동작 번호는 그림 대조로 추정한 임시 대응.
- 완료: Claude의 사냥 16곳·로프/메모리카드·타이틀·확대 사육장을 보존하면서 터치 배치 통합. 썩은 고기 사용·구매 버튼 제거, 원본 고기·알약 도트 적용. 고기 선택 후 바닥 터치 → 자동 접근·먹기, 알약 선택 후 디지몬 터치. 카메라 월드 좌표·저장 먹이 좌표 복원·타이틀 중 입력 차단 검사. 배고픈 케이지 디지몬은 자유 활동으로 나와 먹고, 재입장은 사용자가 지정한다.
- 완료: 216종 원본 스프라이트(발끝·몸 중심·그림자 보정), 계절 8일 달력, 하루 07:00~21:00와 21시 달력 화면, 'From: 안내' 편지 창, 아이템 끌어 주기, 바닥의 똥 하나씩 치우기, 배고픈 디지몬이 바닥 고기로 걸어가기, 상태 말풍선
- 형규 플레이 피드백: 주요 시스템은 들어왔지만 원작과 괴리감이 큼. 특히 사육장 조작과 하루 흐름·연출 (11/12에 1차 반영, 추가 피드백 대기)
- 완료: 재접속 시 오프라인 진행은 21시에서 멈추고 달력을 표시. 밤 저장을 다시 열어도 추가 훈련 없이 다음 날 버튼을 기다림. 새벽·계절말·연말의 달력 날짜와 실제 수면 종료 날짜를 엔진 함수로 통일. Windows CRLF 진화표 로딩 오류 수정.
- 완료: 바닥 먹이 예약분 중복 급여 방지, 먹기 실패 시 먹이 보존, 기존 저장 초과 예약 복구. Esc·바깥 드롭·창 이탈·터치 취소 처리와 포인터 구분, 먹이 드롭이 케이지 이동으로도 처리되던 문제 수정. 규칙·입력 회귀 테스트 추가.
- 완료: 사냥터 배경을 단색 네모에서 원본 지도(낮·밤, 물·용암 포함)로 교체. 사냥터를 원작 16곳으로 늘림(파도치는 해변·바위산·오아시스·암반 계곡·크롬 광산·기계 공장 추가), 출현표를 위키 서식지 표(성장기·성숙기 이상 포함, 밤/낮·드묾)로 교체. 잉카 유적은 챔피언십 우승 뒤 열림. 로프를 성숙기·완전체까지 4단계로 확장(랭크 해금). 지도 번호 짝은 형규 확인 완료 (design.md 표).
- 완료: 타이틀 화면을 참고 화면 스타일(원작 로고·시설 섬·큰 버튼)로, 게임 화면은 사육장이 메인이 되게 재배치. 육각 칸을 원작처럼 크게 키우고 카메라 이동·작은 지도 추가 (옛 저장의 디지몬·먹이 좌표는 자동 변환). 타이틀 중에는 게임 시간 정지.
- 완료: 원작 텍스트(root/ui/txt) 해독 도구 추가. 그 근거로 로프 12종·내구력(끊어짐), 메모리카드(사냥 1회 용량 32/64/96G), 하루 = 현실 10분, 타이틀 엔트리 07:00~15:00 반영. 옛 저장의 로프 단계는 로프 목록으로 자동 변환.
- 완료: 08시를 지나 재접속해도 엔트리 마감 전이면 참가 가능한 경기 안내. 날짜별 실제 읽음 저장으로 중복·미확인 편지 유실 방지. 기존 저장은 읽음 키가 없으면 미확인으로 이어받음. 타이틀·예선·본선과 마감 경계 검사.

## 알아둘 것
- 원본 게임 파일(root 폴더)은 형규 PC `C:\Users\TEST OS\OneDrive\Desktop\root`에만 있다. 저장소에 올리지 않는다
- 사냥 지도를 다시 변환할 때: `python tools/extract_hunt_maps.py "<root 폴더>"` → `web/assets/fields/NN_01.png`(낮)·`NN_02.png`(밤). 쓰는 번호는 스크립트의 `USED`와 game.js `HUNT_MAP`을 함께 고친다
- 타이틀·공통 배경 그림 다시 변환: `python tools/extract_title.py "<root 폴더>"` → `web/assets/ui` (로고·구슬·배경)
- 원작 문장 해독: `python tools/extract_text.py "<root 폴더>" "<출력 폴더>"` (출력은 저장소 밖). 근거는 design.md에 줄 번호로만 적는다
- 스프라이트를 다시 변환할 때: `python tools/extract_sprites.py --source-root "<root 폴더>"`. 이름 대응은 `tools/sprite_names.json` (형규 확인 완료)
- 저장 데이터: 브라우저 localStorage `champion-web-v2`. 형식을 바꾸면 기존 저장을 이어받는 처리를 함께 넣는다
- 테스트: `npm test` (엔진 vitest 49개 + 케이지·터치·안내 node:test 26개). 원본 프레임 범위·유지 시간·상태 전환·정지·먹이 예약/취소와 기존 입력을 검사. 통합 브라우저에서 기존 저장 이어하기, 원본 도트 표시, 바닥 배치 후 자동 섭취도 확인했다. 이 작업 환경은 npm이 없어 같은 scripts를 `pnpm test`, `pnpm run build:core`로 실행했다. `pnpm exec tsc --noEmit`, `python tools/check_web.py`도 통과.
