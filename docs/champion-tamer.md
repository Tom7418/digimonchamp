# 디지몬 챔피언쉽 팬게임 (Champion Tamer)

디지몬 챔피언쉽(NDS, 2008)의 시스템을 웹으로 다시 구현하는 비영리 팬게임.
코드는 전부 새로 작성했고, 원작 ROM에서 꺼낸 그림·음원·코드는 들어 있지 않다.
디지몬 이름, 진화 루트와 조건은 공개 공략 위키의 내용을 게임 데이터로 옮겼다.

## 실행
```
npm install
npm run dev      # 개발 서버
npm test         # 핵심 로직 테스트
npm run build    # dist/ 생성
```

## 구현된 것
- 사육: 여러 마리 동시 사육(용량 200G), 먹이·청소·치료, 병·부상, 수명, 성격 8종
- 케이지: 훈련 케이지에 넣어 두면 능력치와 종족·속성 수치가 오른다
- 진화: 유년기I~궁극체 220여 종. 속성 수치 / 배틀 횟수·승률 / 페널티(발병) / 디지에그화 횟수 / 시간 경과
- 테이머 랭크: 타이틀을 따야 다음 세대로 진화할 수 있다
- 디지에그화와 로스트, 썩은 고기로 페널티 쌓기
- 배틀: 필드 위 자동 전투, 출전 전에 일반·특수·지원 공격 선택, 1:1과 3:3, 제한 시간
- 프리 배틀, 타이틀 매치(날짜 지정), 챔피언십 예선·본선
- 사냥: 로프로 원을 그려 포획 (유년기 서식지와 계절 반영)
- 상점, 달력(계절 10일 × 4), 자동 저장

## 원작과 다른 점 / 아직 없는 것
- 그림과 소리는 임시(색 원 + 이름표, 무음). `src/assets/sprites`, `src/assets/sounds`에 파일을 넣으면 바뀐다
- 종족·속성(백신/데이터/바이러스)과 능력치 수치는 원작 값을 확인하지 못해 진화 조건에서 추정했다
- 타이틀 매치의 이름·일정·상금, 케이지 일부(수영장·새장·묘지·연구실), 수명 길이, 달력 길이는 임시로 정한 값이다
- 필살기 이름과 개별 연출, 내성(더위·추위 등), 케이지 랭크 업, 사냥 도구(탄환·트랩·와이어), 성장기 이상 야생 디지몬, 기억 진화, 통신 대전은 아직 없다

## 구조
- `src/data/evolutions.txt` 진화 표 (한 줄에 한 종)
- `src/core/` 화면과 무관한 게임 규칙: data, care, evolution, battle, titles, save
- `src/scenes/` Phaser 화면: Boot, Farm(사육장), Battle, Hunt
- `src/ui/art.ts` 스프라이트·소리 끼우는 자리
