# 원작 사냥 사운드 선택표

원작 사냥터 16곳에는 서로 다른 배경곡 8개가 쓰인다. 같은 사냥터의 낮·밤 지도는 번호가 달라도 배경곡 번호가 같다. 사냥터 사이에서 같은 곡을 공유하는 경우가 있다.

|---|---:|---:|---|

## 확인 경로

- 사냥터 선택 코드 `overlay9_12 0x02111EB4–0x02111F18`은 ARM9 `0x020C8A78`의 36바이트 행에서 낮·밤 지도 인덱스를 읽는다. 선택한 인덱스는 `[*0x020FF008 + 0x10]`에 저장한다.
- 사냥 시작 코드 `overlay9_0 0x0211A150–0x0211A170`은 그 인덱스로 ARM9 `0x020CA010`의 88바이트 행의 첫 값을 읽고, 음량 127과 함께 `0x0203E044`에 넘긴다. 이 함수가 배경 시퀀스 번호를 넘기는 재생 호출은 `0x0203E0A8`이다.
- 시퀀스 이름은 로컬 `sound_data.sdat`의 `SYMB` 블록에 있는 시퀀스 표로 확인했다.

## 샷과 선 그리기

| 동작 | 재생 인자 | SDAT 항목 | 호출 위치 |
|---|---:|---|---|
| 일반 샷·연사 샷 | `0x0408` | `SEQARC_SE_HUNT[8]` · `HUNT_SE_039_7` | `0x02125F2C`, `0x02125F54` |
| 산탄 | `0x040A` | `SEQARC_SE_HUNT[10]` · `HUNT_SE_039_9` | `0x02125E2C` |
| 선 그리기 루프 | `0x0800` | `SEQARC_SE_HUNT_LOOP[0]` · `HUNT_LOOP_DRAW_LOOP` | `0x02117D78` |

`0x0203DEC4`는 인자의 상위 바이트를 시퀀스 아카이브 번호로, 하위 바이트를 아카이브 내부 효과음 번호로 사용한다. 사냥 동작의 나머지 효과음과 육성·배틀 사운드는 별도로 확인해야 한다.
