# 도감 미등록 실루엣 확인

- 도감 화면 overlay16 `0x0210F414–0x0210F41C`는 각 칸의 등록 바이트와 종 번호를 ARM9 `0x02095368`에 전달한다. 항목 구조체는 종 번호를 +0x24에, 등록 바이트를 +0x30에 둔다.
- ARM9 `0x02095434–0x02095480`은 등록 여부를 검사하기 전에 종 번호로 그림을 불러와 붙인다. 항목 생성자 `0x020952B0`가 참조하는 장면은 `db_digimon_menu_item_scene.nxr`다.
- ARM9 `0x020953A4`와 `0x020953EC`는 그 그림의 색을 설정한다. 미등록은 둘 다 0, 등록은 선택 칸이 0x7FFF, 일반 칸이 0x4210이다. 색 필드 쓰기는 `0x02046780`, 그 값을 렌더 명령에 전달하는 경로는 `0x02045CF8–0x02045D0C`에서 확인했다.
- 확인된 목록 경로의 실루엣은 종별 도감 그림을 검게 표시한 결과다. 그 경로에는 시퀀스 39 호출이 없다.
- 웹판은 자체 공통 실루엣을 검게 표시하고, 등록 목록의 비선택 그림을 조금 어둡게 표시한다. 웹판의 밝기 78%는 가독성을 위해 선택한 값이다. 미등록 칸에 원작의 종별 윤곽을 생성하지 않는다.
